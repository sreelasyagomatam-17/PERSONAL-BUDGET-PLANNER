The Personal Budget Planner is a Flutter-based mobile application designed to help users manage and monitor their personal finances through a simple and user-friendly interface. The application provides an organized dashboard where users can view their income, expenses, savings, and remaining budget. It allows users to add and categorize expenses, set monthly budgets, and track their spending patterns. The UI is designed with clear navigation, attractive visual components, and easy-to-understand financial summaries. The project focuses primarily on developing an intuitive and responsive Flutter UI, providing a foundation for future integration of database storage, expense analytics, notifications, and other financial management features.
